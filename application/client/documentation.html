System Documentation

Operational principles and guidelines for commercial agents managing luxury jewelry orders.

1. Application Overview

The Jewelry Order Management System provides a secure, centralized web portal designed for commercial sales representatives across our fine jewelry branches. It facilitates fast order entry for precious items, automated server-side tax calculations, and reliable order tracking.

2. Operations Guide

Once authenticated, commercial agents have access to the main operations menu, which offers two primary actions:

a) Create a New Order

Enables agents to register jewelry purchases. After entering customer contact details, agents select rings, necklaces, or luxury watches from the official catalog and specify quantities. The PHP backend computes the total price including 21% VAT and saves the transaction.

b) View Orders

Provides access to consultation tools to inspect the complete registry of all store orders in a tabular overview or retrieve specific records using unique Order IDs.
